# Pure Harvest Organics

A premium, responsive organic flour storefront built with Vite, React and the official React Bits AnimatedContent component.

## Development
- Install dependencies: `npm install`
- Start locally: `npm run dev`
- Production build: `npm run build`

## Deploy on Vercel
Import this repository. Vercel will detect Vite; use build command `npm run build` and output directory `dist`.

## Motion components
This project integrates React Bits' `AnimatedContent` (JavaScript + CSS variant), using GSAP ScrollTrigger for scroll-based reveals, blur and subtle 3D tilt. Component source is included in `src/components/AnimatedContent.jsx`.
